    About Me

    Backend developer yang berfokus pada logika, data, dan API yang stabil serta mudah dikembangkan.

    Saya mendalami Laravel lewat pelatihan di Minarsih Tech, lalu mengasahnya lewat magang 6 bulan di PT Humma Teknologi Indonesia pada project GetSkill, dengan Laravel dan Spring Boot. Saya juga terus belajar TypeScript, React, dan CSS supaya memahami produk secara utuh, dari server sampai tampilan.

    Saya pernah mengerjakan project sekolah dari nol sampai jadi sebagai fullstack developer: merancang fitur, bekerja dalam tim, dan menyelesaikan masalah teknis sampai tuntas.

    Saat ini saya siswa kelas 12 RPL di SMKN 2 Mojokerto yang sedang mencari kesempatan kerja di bidang teknologi.
